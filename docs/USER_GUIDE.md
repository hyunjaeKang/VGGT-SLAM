# V1~V5 쉬운 사용 설명서

**그림처럼 읽는 전체 설명서:** [USER_GUIDE.html](USER_GUIDE.html) / [인쇄용 PDF](USER_GUIDE.pdf) · V5를 실행한 뒤 <http://localhost:8107/guide>에서도 볼 수 있습니다. 버전 선택, 명령 복사, 사용 순서, KITTI 영상 위치, 속도/화질 설명, 문제 해결, 인쇄/PDF 저장을 제공합니다.

사진으로 블록 지도를 만든다고 생각하면 쉽습니다. V1/V2는 만들어 둔 지도를 보여 주고, V3/V4/V5는 새 영상으로 지도를 만듭니다.

| 버전 | 쉬운 특징 | 주소 |
|---|---|---|
| V1 Classic | 저장한 지도를 한 장씩 확인 | localhost:8101 |
| V2 Smooth | 저장한 지도를 영화처럼 부드럽게 재생 | localhost:8102 |
| V3 Live | 새 지도와 도로를 계산하고, 완료 후 물체 검색 | localhost:8103 |
| V4 Live | 새 지도 생성 중 미리 정한 물체도 찾기 | localhost:8105 |
| V5 SLAM | 지도 생성에 집중하고 완료 후 필요할 때 물체 검색 | localhost:8107 |

처음 새 지도를 만들려면 **V5 / 해상도378**, 저장된 KITTI 지도를 둘러보려면 **V2**부터 사용하세요. 새 컴퓨터 설치법이 아니라 현재 모델·환경이 준비된 컴퓨터의 구동법입니다.

아래에서 사용할 버전 **하나**를 실행한 뒤 주소를 여세요. 이미 실행 중이면 다시 켜지 않습니다. 8104/8106/8108은 각 생성 버전이 관리하므로 따로 켜지 않습니다.

```sh

.venv/bin/python demo.py live --port 8103 --viewer-port 8104
# V2 · 기존 KITTI 지도 부드럽게 보기
.venv/bin/python demo.py view --run logs/demo_runs/s03_kitti_loop_on_20261031_01 --port 8102 --version smooth --source-fps 10
# V1 · 기존 KITTI 지도 기본 보기
.venv/bin/python demo.py view --run logs/demo_runs/s03_kitti_loop_on_20261031_01 --port 8101 --version classic

.venv/bin/python demo.py versions --port 8100
```

여러 생성 작업은 컴퓨터 자원을 나눠 쓰므로 느려집니다. 현재 작업을 임의로 닫지 말고, 끝나거나 생성 중지한 뒤 다음 작업을 시작하세요.

## V5로 시험하기

1. <http://localhost:8107>에서 **디스크에서 영상 선택**을 누릅니다.
2. `logs/demo_inputs/kitti_closed_loop_508_1855_20261109/kitti_closed_loop_v2_selected_10fps.mp4`를 고릅니다.
3. 추론 해상도 **378**로 시작합니다. 작은 첫 시험은 최대 입력6, 서브맵3, 이동 기준0, 루프1로 실행합니다.
4. **지도 생성 시작**을 누릅니다. 모델 로딩 뒤 서브맵이 완성되면 3D/RGB/BEV가 나타납니다.
5. 전체 구간은 최대 입력 **0**(끝까지)으로 실행합니다. 선택 영상의 모든 이미지를 쓰려면 이동 기준0, 서브맵8, 루프1을 사용합니다.
6. 재생·정지·프레임 막대로 봅니다. 자유 탐색 후 **View Reset**으로 현재 RGB 시점으로 돌아갑니다. BEV는 휠 확대/축소와 끌어 이동을 지원합니다.

재생 정지는 화면만 멈춥니다. 계산을 멈추려면 위쪽 **생성 중지**를 사용하세요. 중지한 계산을 이어서 완성하는 기능은 아직 없습니다.

## 작게 계산하면?

V5 해상도는 실제 계산 크기입니다. 영상 파일만 작게 만들면 기존 버전은 다시518픽셀로 확대하므로 같은 효과가 나지 않습니다.

- **518:** 자세한 점군, 계산량 증가.
- **378:** 기본 균형값.
- **322:** 계산량 감소, 항상378보다 빠른 것은 아님.
- **224:** 시험용, 작은 물체와 구조가 많이 사라질 수 있음.

동일 KITTI4장 모델 계산의 첫 비교는518 약1.98초 /378 약1.25초였습니다. 약1.6배는 **모델 계산만의 비교**이며 전체 처리시간 보장이 아닙니다. 첫 로딩은 따로 걸립니다. 상대 지도 정확도와 새 해상도의 폐루프 성능은 별도 평가가 필요합니다.

V5는 지도 생성 중 자동 검색·도로·하늘 분할을 하지 않습니다. 완료 후 검색 패널에서 객체 검색과 마스크·박스를 사용할 수 있습니다. 하늘이 지도에 남을 수 있습니다. 검색이 필요하면 V4에서 `car,person,bicycle` 같은 사전 대상을 정하세요. 검색20건은 같은 자동차의 여러 관측일 수 있어 자동차20대를 뜻하지 않습니다.

진행·증거: [DEMO_PROGRESS.md](DEMO_PROGRESS.md). V5 기술 세부: [LIVE_V5.md](LIVE_V5.md).

같은 영상6프레임 전체 처리 시험은378 약21.1초/518 약22.4초였습니다. 모델만의 속도 차이보다 전체 대기 시간 차이는 작습니다.

## V5에서 차를 따라가듯 보기

3D상단 **Chase View · 뒤에서 추적**을 누르면 현재RGB카메라보다 조금뒤·위에서지도를따라갑니다. 재생·프레임이동도함께따라갑니다. 너무가까우면오른쪽 **Chase 거리 배율**을높이세요. **자유3D탐색**은추적을끄고직접돌려보기, **View Reset**은원래RGB카메라자리로돌아가기입니다. RGB재생은서버시간에맞춰갱신하며,원본영상읽기실패시프레임사진으로대신보여줍니다.

## 전체 영상 폐루프와 복원된 검색

이KITTI원본전체1,348장을읽고224키프레임을선택한실제시험은1루프/사후오차11.56m/80초였습니다. 전체를모두키프레임으로넣는것과구분하세요.전체원본에는‘KITTI 폐루프 설정’(518/16/이동80/시간간격10)을사용하고,이미선별한226장영상은이동0으로사용하세요.

지도완료후‘검색 · Search’에서car검색→결과선택→RGB/3D/BEV마스크·박스표시가가능합니다. 기본검색은현재RGB한장입니다. 전구간은전구간전수를직접선택하세요. 검색계산은클릭할때만실행하므로지도생성때의계산에는추가하지않습니다.
