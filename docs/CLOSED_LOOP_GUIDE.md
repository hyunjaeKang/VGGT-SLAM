# 전체 영상과 루프 클로저가 성립하는 조건

**1,348장 전체로도 루프 클로저를 시도할 수 있다.** 입력 장수 제한 때문에 실패한 것이 아니다. 다만 모든 프레임을 입력하는 것과 모든 프레임을 지도 키프레임으로 사용하는 것은 다르다. 일반적인 SLAM은 전체 영상을 읽고 지도 계산에 유용한 프레임을 선택한다.

## 일반적인 요건

1. **재방문:** 과거에 본 장소를 다시 보아야 한다. 출발점과 마지막 프레임이 정확히 같을 필요는 없고 중간 구간 재방문도 가능하다.
2. **겹치는 정적 배경:** 건물·도로 시설·벽처럼 같은 구조가 양쪽 영상에 보여야 한다. 정반대 방향, 큰 가림, 큰 조명 변화, 움직이는 차량만의 유사성은 어렵다.
3. **쓸 수 있는 영상과 움직임:** 충분한 선명도·구조·해상도와 적절한 시점 변화가 필요하다. 너무 유사한 연속 사진을 많이 넣는 것이 항상 유리하지 않다. 반대로 너무 띄엄띄엄 고르면 연속 지도 연결이 끊어질 수 있다.
4. **장소 후보와 기하 검증:** 비슷하게 보인다는 것만으로 연결하지 않고, 실제 상대 위치·깊이·대응 관계가 일관적인지 확인해야 한다.
5. **안정적인 지도 연결·최적화:** 재방문 제약을 그래프에 추가한 뒤 누적 오차를 보정할 수 있어야 한다. 잘못된 제약은 지도를 더 나쁘게 만들 수 있다.
6. **결과 검증:** 후보/수락 수와 최종 지도 정확도는 다르다. 가능하면 기준 궤적, 연결 전후 모양, 재방문 쌍을 확인한다.

VGGT-SLAM은 서브맵과 루프 제약을 SL(4) 그래프에서 정렬한다. ORB-SLAM의 경우도 장소 인식 외에 시간적·기하적 일관성 검증을 사용한다. 구체적인 임계값은 시스템과 영상에 따라 다르다. **10초 제외는 이 데모의 조절 가능한 설정이며 루프 성립의 보편 법칙이 아니다.** 시간 압축된226장 영상에서의10초는 원본 주행10초가 아니다.

출처: [VGGT-SLAM 논문](https://arxiv.org/abs/2505.12549), [ORB-SLAM 논문](https://arxiv.org/abs/1502.00956).

## V5의 검색·마스크·박스

처음 V5는 지도 속도를 비교하기 위해 검색·분할을 숨긴 별도 버전이었다. 후속 사용자 요청으로 **생성 완료 후 필요할 때 실행하는 검색**을 복원한다. 지도 계산 중 자동으로YOLO/SAM3/ROAD/sky를 돌리는 V4 방식과 구분한다.

- 검색 패널: 현재 RGB(기본), 전구간 전수, 표본, PE 후보 검색.
- RGB: 객체 마스크·2D bounding box 켜기/끄기.
- 3D: 유효 깊이를 가진 객체 박스와 분할 점 표시.
- BEV: 마스크·박스 켜기/끄기.
- Clear object boxes: 선택 결과와RGB/3D오버레이 해제.

전구간 검색은 별도 CPU 추론 시간이 든다. 검색 모델은 사용자가 검색할 때만 실행하고 지도 생성의 기본 계산에는 포함하지 않는다. 마스크가 있어도 유효 깊이가 부족하면3D박스는 생기지 않을 수 있다.
