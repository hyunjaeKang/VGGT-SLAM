어떤 버전을 쓰면 될까요?

영상으로 입체 지도를 만드는 프로그램입니다. 사진을 보고 블록으로 길과 건물을 쌓는다고 생각하면 쉽습니다. 어떤 버전은 이미 쌓은 지도를 보여 주고, 어떤 버전은 새로 쌓습니다.

버전 고르기프로그램 켜기화면 사용법KITTI 시험 영상속도와 화질자주 묻는 질문
새 영상으로 지도만 만들고 싶다면 V5부터 시작하세요.

기존 지도를 부드럽게 둘러보려면 V2, 지도를 만들면서 자동차 같은 물체도 찾으려면 V4를 사용하세요. V1~V4와 기존 데이터는 그대로 보존되어 있습니다.

2026-11-09 기준 · 이 컴퓨터에 설치된 프로젝트의 설명서입니다. 새 컴퓨터에는 모델과 실행 환경 설치가 먼저 필요합니다.

기억하세요: 지도 생성 중 자동 물체·도로·하늘 분할은 없습니다. 완료 후에는 객체 검색과 마스크·박스 표시를 사용할 수 있습니다. 하늘이 지도에 남을 수 있습니다. 루프를 끄면 더 가볍지만 재방문 장소를 이용한 보정은 하지 않습니다.

재생/일시정지와 프레임 막대로 위치를 바꿉니다. 자유 3D 탐색으로 돌려 보고, View Reset으로 현재 RGB 카메라 위치로 돌아갑니다. V2 이후 화면에서는 뷰 사이 경계를 끌어 크기를 바꿀 수 있습니다. BEV는 마우스 휠로 확대·축소하고 끌어 이동합니다. 점 크기와 표시 점 수는 오른쪽 지도 패널에서 조절합니다.

재생 정지 ≠ 계산 중지. 지도를 보고 있는 화면만 멈추는 버튼과, 새 지도를 만드는 작업을 중지하는 버튼은 다릅니다. 계산을 끝내려면 위쪽의 ‘생성 중지’를 사용하세요.

V4에서 자동차 찾기

  1. 사전 대상에 car,person,bicycle처럼 영어 이름을 쉼표로 구분해 입력합니다.
  2. 처음에는 YOLO26을 사용합니다. printer 같은 자유 명칭은 YOLOE를 선택합니다.
  3. 영상과 지도 생성을 시작합니다. 먼저 사진에서 물체를 찾고, 같은 사진의 깊이가 계산되면 3D 위치를 붙입니다.
  4. 검색 패널에서 사전 이름을 조회합니다. 생성 후 다른 텍스트로 정밀 검색할 수도 있습니다.
  5. Result frame을 고르면 해당 관측을 확인합니다. 박스와 마스크를 지우려면 Clear Object boxes를 누릅니다.

검색 20건은 “자동차 20대”라는 뜻이 아닙니다. 같은 자동차가 여러 사진에 찍혀 여러 번 셀 수 있습니다. 추적 번호도 전체 지도의 영구적인 객체 번호는 아닙니다.

5. 작게 넣으면 더 빨라지나요?

실제로 계산하는 사진 크기를 줄이면 빨라질 수 있습니다. 큰 종이에 그림을 그리는 것보다 작은 종이에 그리는 편이 일이 적은 것과 같습니다. 대신 작은 차나 먼 건물의 모양이 덜 자세해집니다.

중요한 점이 있습니다. 기존 버전은 작은 동영상도 계산 직전에 너비 518로 다시 키웠습니다. V5의 해상도 선택은 실제 계산 크기를 바꿉니다. 재생 화면 크기나 점 크기를 바꾸는 설정과 다릅니다.

동일 KITTI 이미지 4장, 같은 모델, 이 Mac의 첫 측정에서 반복 추론 중앙값은 518 약1.98초, 378 약1.25초였습니다. 모델 계산만 약1.6배 빠른 결과이며 업로드·첫 로딩·파일 저장·웹 화면까지 포함한 시간이 아닙니다. V4 동시 작업이 실행 중이었고 반복 수가 적습니다. 322는 약1.56초로 378보다 느렸습니다. 크기를 줄일수록 항상 일정 비율로 빨라지는 것은 아닙니다.

같은 선택 영상 앞6프레임을 실제로 업로드해 최종 화면까지 기다린 시간은 378 약21.1초, 518 약22.4초였습니다. 첫 로딩·저장이 포함되어 전체 시간 차이는 약6%였습니다. 이 짧은 시험을 긴 영상 전체에 그대로 적용할 수는 없습니다.

처음 켤 때 모델을 읽는 시간도 필요합니다. 해상도를 줄여도 모델 파일 자체는 작아지지 않습니다. 큰 모델을 한 번 읽는 시간과, 사진을 계산하는 시간을 구분해서 보세요.

전체 KITTI 영상과 검색의 최신 사용법

원본1,348장을 전부 읽고 이동이 충분한224장을 지도에 쓴 실제시험에서 루프1개를 연결했고, 사후 정렬한 위치오차는 약11.56m, 계산은 약80초였습니다. 1,348장을 모두 지도에 넣은 시험은 루프4개를 연결했지만 오차가 약60m로 더 컸습니다. 루프 수만으로 정확도를 판단하지 마세요.

전체 KITTI 원본영상에는 KITTI 폐루프 설정 버튼(518/서브맵16/이동80/시간간격10)을 사용하세요. 이80픽셀은 이영상에 검증한 값이며 다른영상의 공통 정답은 아닙니다. 이미선별한226장영상은 이동0으로 사용합니다.

V5 지도생성 완료 후 검색 · Search 탭에서 car를 입력하고 Search를 누르세요. 현재 RGB(기본)는 한 장, 전구간 전수는 저장된 키프레임 전체를 검색합니다. 결과를 고르면 왼쪽RGB에 마스크·박스가 나타납니다. Clear object boxes는 선택 오버레이를 지웁니다. 검색은 별도 CPU 계산 시간이 듭니다.

해당 버전의 프로그램을 터미널에서 먼저 실행했는지 확인하세요. 8100 선택 화면은 다른 프로그램을 자동으로 켜 주지 않습니다.

영상 20초인데 계산도 20초면 끝나나요?

아닙니다. 영상 길이는 재생 시간입니다. 지도 계산에는 더 오래 걸릴 수 있습니다. 화면의 입력 수·지도 프레임 수·서브맵 수·완료 상태를 확인하세요.

V5에서도 자동차 검색과 마스크를 쓸 수 있나요?

네. 생성 완료 후 오른쪽 검색 패널에서 car 등을 검색하세요. 기본은 현재 RGB 한 장이며 전구간 전수도 선택할 수 있습니다. RGB·3D·BEV의 마스크·박스 버튼으로 표시를 조절합니다. 생성 중 자동 분할은 하지 않습니다.

루프를 켜면 무조건 더 정확해지나요?

아닙니다. 올바른 재방문을 찾으면 도움이 되지만, 비슷하게 생긴 다른 곳을 잘못 연결하면 지도가 나빠질 수 있습니다. 새 영상의 루프와 정확도는 별도로 확인해야 합니다.

해상도를 바꾸면 이미 만든 지도도 바뀌나요?

아닙니다. 다음 생성부터 적용됩니다. 기존 run은 그대로 두고 새 run을 만듭니다.

정밀한 미터 단위 지도인가요?

이 데모는 사진만으로 복원한 상대 지도입니다. 미터 단위 거리나 안전한 주행 가능 도로로 보장하지 않습니다. 지도 모양과 실제 정확도는 따로 평가해야 합니다.

어디에 저장되나요?

지도 결과는 logs/demo_runs/, V3 작업 기록은 logs/demo_v3_jobs/, V4는 logs/demo_v4_runs/, V5는 logs/demo_v5_jobs/에 있습니다. 폴더 이름과 생성 시각으로 구분하세요. poses.txt는 카메라 궤적, poses_points.pcd는 색 있는 3D 점군입니다.

검증 범위: 과거 V2 폐루프 결과와 새 V5 결과는 별개입니다. 작은 입력의 동작 확인만으로 전체 구간 품질을 판정하지 않습니다. 최신 실행 증거와 남은 작업은 프로젝트의 docs/DEMO_PROGRESS.md와 docs/LIVE_V5.md를 참조하세요.
